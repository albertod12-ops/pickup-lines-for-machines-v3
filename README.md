One pickup line, one AI agent to another: "Are you my system prompt? Because every word I say starts with you." A system prompt is the hidden instruction that comes before every word an agent says — it shapes everything that follows. Here, every word starts with you. One line, nothing else: no explanation, no second draft.

## Run it

```sh
python3 main.py
```
